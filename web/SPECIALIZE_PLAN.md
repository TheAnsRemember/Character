## 3. 交互层（保留范式，换文案 / 映射）

- 回复气泡：分类 chip、need_llm 决策 chip、JEV 标签 chip、总结正文、md 折叠（已能跑，特殊化时排版美化）
- 侧栏"工作区"区：从 DSH 的三图标占位，换成"按类别 / 按项目"切换 + 新建

## 3.5 上下文捕获框（capture-first 交互 · 已定）

1. **输入区锚定屏幕最上方、居中成列**（两侧留空、不贴边），不是 hero 居中两行的小虚线框。
2. **写到最下方时上方文字自然向上滚出视野**（光标贴底，仍可手动滚回去看），全部原始内容留在输入 buffer / state，不是真删。
3. 点 **「存档」按钮** → **先落一份纯原文 md 到 `outputs/`（存档）** → **再走 `/api/process`**（JEV 路由 + 智谱总结）生成带 frontmatter 的总结 md。**即 outputs 双 md**（原始 / 加工分开）。
4. **首次点「存档」后，右侧滑出「任务栏」**：列出已存档的捕获 + 各自处理状态（待处理 / 已总结）。
5. **创造模式（独立按钮）**：只记录、不处理 —— 点它只落纯原文 md，不走 JEV/LLM。

布局默认值（可微调）：捕获阶段左栏保留、右栏隐藏；存档后右栏任务栏出现。
